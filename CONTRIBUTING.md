# Contributing

## Documentation is part of every feature

When a change adds or changes runtime behavior, update `PROJECT_GUIDE.md` in the same commit. Update `README.md` when quick-start instructions, prerequisites, or advertised capabilities change. The pull-request template records this review, and the documentation workflow requires a documentation-file change whenever Python source changes.

Before opening a pull request:

- Run the relevant local command or benchmark.
- Update the walkthrough, design decisions, limitations, and validation notes in `PROJECT_GUIDE.md`.
- Check the documentation box in the pull-request template.
- Keep credentials, videos, and other sensitive data out of the repository.

For non-functional formatting-only source edits, add a brief explanation in the pull request if no documentation change is needed.
